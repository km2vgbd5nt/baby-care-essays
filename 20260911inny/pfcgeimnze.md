# 脱水蔬菜条、低脂饼干、无糖沙拉 这些“健康食品”营养师都不吃，真的吗？

> 更新时间：2026-09-11 (UTC+8)

果味酸奶、蛋白粉、低脂食品、排毒果汁……随着人们越来越重视健康，这些贴着“纯天然”“健康”“营养”标签的食品也是越来越多。不过这些“健康食品”真的有包装上标榜的那些作用吗？最近美国《女性挚友》网站上载文，刊出了多种美国营养师不吃的“健康食品”，揭开这些食品背后的真相。这份榜单也是在微信上被热转。这些说法都有道理吗？本报也请来营养师详细分析一番。

“水果+酸奶”不等于健康食品

国内外的各种饮食指南都会建议食用充分的蔬菜水果。但是市面上的各色水果制品，也未必是健康食品了。

减肥人群有时会盲目采用极端的方法，净化断食减肥法就是其中一种。这种减肥法要求一段时间内不吃食物，只允许喝果汁，称这种饮食方法有净化排毒，给身体注入活力的功效，但是纽约理工学院程序开发部门主任兼注册营养师Mindy Haar博士指出，“根本没有这种生理现象，这种果汁含有大量的糖分，而且水果所含的纤维在被制成果汁时也大量流失”。中大医院营养科主任王春香也表示，单纯喝果汁并不能达到排毒的功效，果汁中含有大量糖分，且不含膳食纤维，不建议以此来达到减肥的目的，还是要合理安排饮食配合运动。

爱因斯坦医学院副教授、博士兼注册营养师Yasmin Mossavar-Rahmani说道，“水果和酸奶都是健康食品，但水果味的酸奶却含有过高的糖分”。对水果味的酸奶，王春香也持否定态度，这种水果味酸奶是经过加工的，并不含原水果的维生素和膳食纤维，更多可能只是糖分的增加，并不能起到真正吃水果的作用。

“低脂”一样会让你胖

美眉们都想保持好身材，对“脂肪”两个字避之不及。如果两瓶牛奶中一瓶标了“低脂”的话，显然更有吸引力。不过在营养专家们看来，所谓的“低脂”并不像字面上一样是健康保证。

帖子里就点名了两种“低脂食品”——低脂花生酱和低脂饼干。在一所心脏医院工作的注册营养师Emily Hein说，“食品加工商在去除某一成分后必然会加进另一种成分。花生酱是用成熟了的花生制成的，而成熟花生含有超高的脂肪，把脂肪这个成分移除后，钠和糖分会自然而然的被加进去。

王春香表示，低脂不等于无脂，而且饼干本身含有大量碳水化合物，食用过多仍会导致能量超标，多余的能量在体内也会转化为脂肪。低脂花生酱作为辅助食品，虽然脂肪含量低了，但热量并不会减低，所以还是建议尽可能少量食用。

“蔬菜条”跟薯条是一类食品

这里说的蔬菜条并不是现成蔬菜切成的条，而是有一段时间流行的硬硬脆脆的包装食品。这种食品曾经很受白领们的欢迎。在帖子里，美国注册营养师Emily Rubin就表示：“如果只是因为‘蔬菜’这个词看起来更健康，而选择蔬菜条不是薯片，这是在自欺欺人”。这是因为蔬菜条的配料表上第一个就是土豆(生粉)和油，所以蔬菜条和薯片所含的成分是一样的，可以说是相同的食品。

中大医院营养科主任王春香也同意这种说法。王主任表示，所谓蔬菜条往往是经过脱水、烘干等多道程序加工合成的。在制作过程中还可能加有添加剂，偶尔当作零食吃一吃可以，但不建议经常食用。

“无糖沙拉”能量也很高

Welstead是一名硕士，现在芝加哥大学的医学院担任营养师，她着重揭露的是无糖沙拉酱的“谎言”。她表示，“食品加工商去除糖时，为了有更好的口味，他们可能会加入脂肪和碳水化合物，而这两种成分在进入人体后，也最终都会分解成为糖分”。所以即使是用无糖沙拉酱拌出的沙拉，能量也会高。

王春香也表示，市场上的沙拉酱，为了迎合大众的口味，都会加入大量的食用油，即使糖分含量低，脂肪含量也很高。另外不值得相信的还有无糖饮料和无糖苏打水。这类罐装饮料会添加其它甜味剂和色素香精等，对健康毫无益处。

“高蛋白”并不是人人都需要

原来蛋白粉是运动员用来在训练前后恢复身体肌肉的专用产品，不过现在不光是健身的人，像中老年人、生长发育期的孩子甚至是大病手术之后都流行吃蛋白粉，这有必要吗？会不会对身体反而有害呢？ 有美国营养师指出，“大多数美国女性实际获得的蛋白质是其真正所需的2倍，即使你大量运动，每天所摄取的蛋白质都是过量的。”

王春香也告诉记者，如果不是确诊的低蛋白血症，或有其它特殊需要，长期过量摄入蛋白质，会加重肝肾等器官的负担，打破机体能量供给模式，导致代谢紊乱。一般情况下正常饮食中就可以获取充足的蛋白质，无需额外摄入蛋白粉补充蛋白质。
